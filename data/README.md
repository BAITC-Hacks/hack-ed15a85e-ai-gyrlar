# Данные StockPilot

`dataset.json` — локальный набор данных для расчёта пополнения. Он создаётся из двух архивов партнёра и не включается в Git. На другом компьютере выполните импорт заново.

## Импорт

Из корня проекта, Python 3.10+:

```powershell
python -m pip install -r requirements.txt
python -X utf8 -m replenishment.importer --archives "C:\Users\Мико\Downloads\IEK.zip" "C:\Users\Мико\Downloads\Systeme electric.zip"
python app.py
```

Замените пути на расположение своих архивов. Распаковывать вручную не нужно. Для уже распакованных каталогов доступен `--source`, как описано в основном README. Импорт не меняет исходные архивы или Excel. Перезапустите приложение после повторного импорта.

## Структура JSON

| Поле | Содержание |
|---|---|
| `version`, `as_of` | Версия схемы и дата среза данных |
| `items` | Каталог, история, остатки, поставки и ограничения по товарам |
| `seasonality` | 12 исходных коэффициентов по каждому поставщику |
| `sources` | Тип, имя, поставщик, размер и SHA256 каждого Excel-файла |
| `diagnostics` | Счётчики сверки, корректировок и найденных аномалий |
| `limitations` | Ограничения предоставленных материалов |

### Поля товара

| Поле | Значение |
|---|---|
| `id` | Уникальный ключ `supplier:code` |
| `supplier`, `code`, `article`, `name` | Поставщик, код 1С, артикул, наименование |
| `unit`, `category` | Единица учёта и категория из источника |
| `sales` | Словарь `YYYY-MM → количество продаж`, с исходными корректировками |
| `stock_history` | Месячные снимки остатков; пропуск сохраняется как `null` |
| `stock`, `stock_date`, `stock_basis` | Выбранный остаток, дата и основание выбора |
| `transit` | Поставки: `qty`, `eta`, `source` |
| `pack`, `moq` | Кратность и минимальная партия; это разные ограничения |
| `outlier_removed` | Объём исключения по месяцам после сверки источников |
| `anomalies` | Найденные всплески: дата, фактический и регулярный объём, причина |
| `sources`, `warnings` | Происхождение данных и замечания |
| `stockout_days` | Необязательное число подтверждённых дней отсутствия по месяцам |
| `source_growth` | Необязательный исторический коэффициент роста из ведомости SE |

`null` означает неизвестное значение, а `0` — известный ноль. Количества разных единиц измерения не складываются. Каталог объединяется по поставщику и коду 1С, без сопоставления по похожим названиям.

## Что нужно дополнить для рабочего пилота

- Актуальные свободные остатки IEK: сейчас доступен снимок на 01.09.2026. У части Systeme Electric также только месячный снимок.
- Обезличенный ID клиента для анализа крупных продаж одному клиенту. Номер накладной не заменяет ID клиента.
- Подтверждённые интервалы отсутствия товара: шаблон `templates/stockouts.csv`. Пустой месячный остаток не подтверждает stockout.
- Сроки поставки по поставщикам, категории IEK и коэффициенты пересчёта закупочных единиц.

В разделе «Источники данных» приложения можно просмотреть полноту данных и результаты сверки. Рекомендации с устаревшим остатком или неизвестной кратностью требуют ручной проверки.
